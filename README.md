# Project-Sutra-Pintar
Sutra Pintar: Alat Mendeteksi Penghitung Rakaat dan Sujud Otomatis Berbasis Sensor Ultrasonik dan OLED (Catatan: Perangkat versi v2.0 menggunakan TFT LCD Touchscreen).

Sutra Pintar merupakan perangkat bantu ibadah berbasis mikrokontroler ESP32 yang dirancang untuk membantu pengguna mengikuti urutan gerakan sholat serta menghitung rakaat dan sujud secara otomatis menggunakan metode Finite State Machine (FSM).

ESP32-based smart prayer assistant featuring dual ultrasonic sensors with Finite State Machine (FSM), TFT LCD touchscreen, and DFPlayer Mini for automatic raka'at &amp; sujud detection.
